## AI Summary

The two I just ran:

```bash
git log @{u}..HEAD --stat        # commit list + files, not-yet-pushed only
git diff @{u}..HEAD --name-only  # just the filenames
```

Other equivalents/related ones worth knowing:

```bash
git status                        # summary line: "ahead of 'origin/main' by N commits"
git log origin/main..HEAD         # same as @{u}..HEAD but spelled out explicitly
git cherry -v origin/main         # lists unpushed commits by SHA + message (works even without upstream tracking set)
git diff @{u}..HEAD               # full diff (not just filenames) of everything unpushed
```

`@{u}` is shorthand for "the upstream of the current branch" (here, `origin/main`), so it always tracks whichever branch you're on — swap it for an explicit `origin/<branch>` if you want to check a specific one regardless of what's checked out.
